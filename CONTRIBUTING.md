# Contributing.md

1. **no AI generated content (no exception, can't be used for creating issues, writing comments, pull requests, code or everything else) - found breaking this rule user will be banned from contributing to this repository in any way**
2. write code in similar style as other parts of codebase
3. write only comments when needed (code should be "self documenting", vars, funcs, structs etc. should have exact, precise names etc.)
4. create issues for any work done and link PRs into them (this is preferred behavior) - preferably also assign yourself to issue you want to solve, if issue if isn't updated in any way for a long time, you can claim it for yourself
5. all test shall run same as before, if test pass-rate changes with your PR changes (with exception of adding new correct test that should pass but don't), it will not be merged

> This is subject to change at any time without further notifications
